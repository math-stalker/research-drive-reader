Privacy Policy

research-drive-reader · Last updated: November 8, 2026

What this app is

research-drive-reader is a personal tool used only by its developer. It is not offered to the public. It reads research PDF files from a single Google Drive folder and copies them to the developer's own computer.

Google user data the app accesses

The app requests the read-only Google Drive scope (drive.readonly). It uses this access only to list and download files from one specific folder.

How the data is used and stored

  • Downloaded files are stored only on the developer's own computer.
  • The app's sign-in token is stored only in a local configuration file on that computer.
  • No Google user data is sold, shared with third parties, used for advertising, or published.
  • The app cannot modify, upload, or delete anything in Google Drive.

Retention and deletion

The developer can delete the downloaded files and the local token at any time. Access can also be revoked at any time at myaccount.google.com/permissions.
